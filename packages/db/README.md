# @komzot/db

Prisma ORM 7 database package for PostgreSQL.

## Stack

- Prisma 7.10.1
- `prisma-client` generator (TypeScript output)
- `@prisma/adapter-pg` + `pg`
- Prisma config with explicit environment loading

## Structure

```
packages/db/
├── prisma/
│   ├── schema.prisma
│   └── migrations/
├── prisma.config.ts
└── src/
    ├── client.ts
    ├── index.ts
    └── generated/prisma/   # generated, gitignored
```

## Database

The root `compose.yaml` starts a dedicated Postgres 18.6 container:

```sh
npm run db:up
npm run db:down
npm run db:logs
```

Connection settings live in the root `.env`:

```env
DATABASE_URL="postgresql://komzot:komzot@localhost:5432/komzot?schema=public"
```

`prisma.config.ts` loads that file explicitly, so CLI commands work from any workspace directory.

## Commands

From the repository root:

```sh
npm run db:generate        # prisma generate
npm run db:migrate         # prisma migrate dev
npm run db:migrate:deploy  # prisma migrate deploy
npm run db:studio          # Prisma Studio
```

From this package:

```sh
npm run generate
npm run migrate -- --name <migration-name>
npm run migrate:deploy
npm run studio
```

## Usage

```ts
import { prisma } from "@komzot/db";

const users = await prisma.user.findMany();
```

`src/client.ts` creates a single `PrismaClient` with the `pg` driver adapter and reuses it in development to avoid connection exhaustion.

## Schema and migrations

1. Edit `prisma/schema.prisma`.
2. Run `npm run db:migrate -- --name <migration-name>`.
3. Commit the generated migration and updated schema.

Regenerate the client after schema changes:

```sh
npm run db:generate
```

## Better Auth schema

The auth tables are generated by the Better Auth CLI. See [packages/auth/README.md](../auth/README.md) for the command and workflow.

## Notes

- The generated client is excluded from git and must be generated after installation.
- `typecheck` runs `prisma generate` first.
- `DATABASE_URL` is required for migrations and runtime queries.
