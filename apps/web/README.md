# KomZot web

Next.js 16 App Router application with TypeScript.

## Stack

- Next.js 16 (App Router, Turbopack)
- React 19.3
- TypeScript
- Shared components from `@komzot/ui`
- Vitest + React Testing Library for unit and component tests
- Playwright for end-to-end tests

## Running

From the repository root:

```sh
npm run dev:web
```

Or from this directory:

```sh
npm run dev
```

The app is available at http://localhost:3000.

## Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Next.js dev server |
| `npm run build` | Create a production build |
| `npm run start` | Start the production server |
| `npm run test` | Run Vitest once |
| `npm run test:watch` | Run Vitest in watch mode |
| `npm run test:coverage` | Run Vitest with V8 coverage |
| `npm run test:e2e` | Run Playwright tests |
| `npm run test:e2e:ui` | Open Playwright UI mode |
| `npm run lint` | Run ESLint |
| `npm run typecheck` | Run TypeScript without emitting |
| `npm run clean` | Remove build, coverage, and test artifacts |

Root aliases:

```sh
npm run dev:web
npm run test:web
npm run test:e2e
```

## Testing

Unit and component tests use Vitest, React Testing Library, and jsdom. The config is in `vitest.config.mts`, with setup in `vitest.setup.ts`.

```sh
npm run test
npm run test:coverage
```

End-to-end tests use Playwright from `e2e/`. The config starts the dev server locally and the production server in CI.

Install the browser once:

```sh
npx playwright install chromium
```

```sh
npm run test:e2e
```

## Shared UI

Components come from the source-only `@komzot/ui` workspace package:

```tsx
import { Button } from "@komzot/ui";
```

`next.config.ts` includes `@komzot/ui` in `transpilePackages` so Turbopack compiles the shared TypeScript source.

## Environment

Use `NEXT_PUBLIC_*` variables for values exposed to the browser. Local env files are ignored by git.

## Notes

- `AGENTS.md` at the app root is auto-generated by `next dev`; commit it to keep the working tree clean.
- React is pinned to `19.3.0` to match Expo SDK 58 and avoid duplicate React copies across the monorepo.
- Story files are excluded from the Turbo `build` task inputs, so changing a story does not invalidate the web build.
